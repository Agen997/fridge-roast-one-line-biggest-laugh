A make.fun bounty entry: one line (max 200 characters) roasting a smart
fridge. `main.py` (Python 3.13, stdlib only) scores six original candidate
roasts against the judge brief's five criteria — on-subject, punchline,
smart-fridge specificity, tight wording, freshness — in the brief's own
order (weights 5/4/3/2/1) and writes the winner to `/output/entry.txt`.

The winning line (117 characters):

> I asked my fridge for ice. It demanded a software update, my Wi-Fi password, and time to reconsider our relationship.
